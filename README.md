# n8n-nodes-hemmilicious-webuntis

n8n Community Node for WebUntis.

## Features

- WebUntis Secret authentication
- QR URL configuration
- Credential connection test
- Get current WebUntis user information
- Get today's timetable
- Get timetable for a specific date
- Get timetable for a date range
- Normalized timetable output

## Installation

Install in self-hosted n8n via:

Settings → Community Nodes

Package:

n8n-nodes-hemmilicious-webuntis

## Security

Credentials, QR URLs, secret keys and session IDs must be stored only through the n8n Credential system and must not be exposed in workflow output or logs.
